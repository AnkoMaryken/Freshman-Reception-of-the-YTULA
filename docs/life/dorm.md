# 宿舍与生活

宿舍是你在大学的「家」，了解宿舍安排与生活配套，帮你更快安顿下来。

## 一、宿舍概况

- **宿舍类型**：以学院/学校统一安排为准，一般为 4-6 人间，配备书桌、衣柜、床铺。
- **床铺尺寸**：标准单人床（具体尺寸可咨询学院或宿管）。
- **生活配套**：宿舍楼通常配有公共洗漱间/淋浴间、开水房、洗衣房等。

::: tip 提示
宿舍分配一般由学校统一安排，报到时查询；如对宿舍有特殊需求（如身体原因），提前联系辅导员说明。
:::

## 二、入住流程

1. 报到时领取宿舍钥匙/入住凭证。
2. 到对应宿舍楼找宿管老师办理入住登记。
3. 领取卧具（如学校统一提供）或自备。
4. 检查宿舍设施，如有损坏及时报修。

## 三、生活用品采购

- **校园超市**：日常用品齐全，价格合理。
- **网购**：快递可寄到校内快递点/驿站（地址填学校地址即可，具体收货点以通知为准）。
- **周边商圈**：学校周边有超市、商场，可补充采购。

::: tip 小贴士
建议先列清单再采购，避免重复购买；开学季校内外超市常有促销活动。
:::

## 四、宿舍生活公约

- **作息**：尊重他人作息，熄灯后保持安静。
- **用电安全**：遵守宿舍用电规定，不使用大功率违规电器。
- **卫生**：轮流值日，保持宿舍整洁。
- **财物**：贵重物品妥善保管，出门锁好门窗。
- **访客**：遵守宿舍访客管理规定，不私自留宿他人。

::: warning 安全提醒
宿舍严禁使用违规电器（如电炉、热得快、大功率吹风机等），严禁私拉乱接电线，共同维护宿舍消防安全。
:::

## 五、校园网络与电话卡

- **校园网**：报到后按学校通知办理开户，登录上网。
- **手机卡**：可在校内营业厅/迎新点咨询办理，货比三家，谨防推销陷阱。
- **校园卡**：就餐、门禁、图书馆、超市消费一卡通，丢失后及时挂失补办。

## 六、快递与邮寄

- **收货地址**：填写「山东省烟台市 + 学校详细地址」，具体格式以学院通知为准。
- **快递点**：校内或校门口通常设有快递驿站，凭取件码取件。
- **寄件**：驿站支持寄件服务。

## 七、日常维修与服务

- **报修**：宿舍设施损坏，联系宿管或在报修系统提交。
- **开水/淋浴**：按楼栋设施使用。
- **洗衣**：洗衣房自助洗衣机扫码使用。

## 八、生活贴士

- 报到后先熟悉**校园地图**：教学楼、食堂、图书馆、医务室的位置。
- 保存几个常用电话：辅导员、宿管、保卫处、医务室。
- 初到烟台，注意天气变化，早晚温差可能较大。

::: tip 需要帮助？
宿舍生活有任何问题，第一时间找宿管老师或辅导员，也可以去学生事务中心咨询。
:::
