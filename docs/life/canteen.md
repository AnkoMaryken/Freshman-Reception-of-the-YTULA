# 食堂与美食

吃饱吃好，才有精力学习！来了解一下学校的餐饮情况。

## 一、校内食堂

学校设有多个食堂，分布在教学区和生活区，提供早、中、晚三餐：

- **菜品种类**：家常菜、面食、小吃、快餐、清真窗口等，选择丰富。
- **就餐方式**：刷校园卡或扫码支付。
- **营业时间**：早餐约 6:30 开始，晚餐持续到 19:00 左右，具体以各食堂公告为准。

::: tip 小贴士
开学初建议把每个食堂都尝一遍，找到适合自己的「宝藏窗口」。
:::

## 二、就餐小贴士

- **错峰就餐**：中午 12:00 左右是就餐高峰，可适当错峰。
- **打包带回**：支持打包，带回宿舍就餐注意保持宿舍卫生。
- **饮食安全**：选择卫生条件好的窗口，如有腹泻等不适及时就医。

## 三、校园周边

- 学校周边通常有餐饮街、小吃摊点，选择丰富。
- 外卖平台可配送至校门口/指定取餐点。

::: warning 注意
外出就餐、点外卖时注意食品安全与卫生，选择正规商家。
:::

## 四、饮食与健康

- 大学食堂营养搭配相对均衡，注意荤素搭配。
- 烟台临海，海鲜丰富，过敏体质的同学注意忌口。
- 保持规律三餐，少熬夜少吃夜宵，身体是学习的基础。

## 五、常见问题

### Q: 校园卡在哪里充值？

**A:** 通过校园卡充值平台/自助充值机/食堂充值点等渠道，具体以学校通知为准。

### Q: 食堂支持微信/支付宝支付吗？

**A:** 多数学校支持校园卡 + 扫码支付两种方式，以食堂实际设施为准。

### Q: 有清真窗口吗？

**A:** 通常设有清真窗口，具体分布可询问食堂工作人员。
