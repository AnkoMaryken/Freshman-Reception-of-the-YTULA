# 学习指南

大学的学习方式与高中差异很大，这里帮你快速了解学院的专业设置、课程体系与学习方法。

## 一、学院专业简介

文学与新闻传播学院依托烟台大学人文底蕴，培养具有扎实专业素养的应用型人才。具体专业设置以学院当年招生计划为准，常见专业方向包括：

- **汉语言文学**：文学理论、古代/现代/当代文学、写作学等
- **新闻学 / 传播学**：新闻采写、编辑出版、媒介传播等
- **网络与新媒体**：新媒体运营、内容创作、数据分析等

::: tip 提示
各专业的培养方案、课程大纲以学院正式发布为准，报到后的专业介绍会也会有详细说明。
:::

## 二、课程体系概览

大学课程通常分为：

| 类型 | 说明 |
|------|------|
| 公共必修课 | 思政、英语、体育、计算机等，全校统一 |
| 专业必修课 | 本专业的核心课程 |
| 专业选修课 | 根据兴趣选择的专业拓展课程 |
| 通识选修课 | 跨学科兴趣课程（人文、艺术、科技等） |
| 实践环节 | 实习、实训、毕业设计/论文等 |

## 三、选课指南

- **选课时间**：一般在每学期末/开学初，留意教务系统通知。
- **选课平台**：学校教务系统（具体网址以学院通知为准）。
- **学分要求**：每学期有学分上限与下限，注意合理规划。
- **课程冲突**：选课前先查看培养方案，避免时间冲突。

::: warning 注意
选课期间网络可能拥堵，建议提前登录、多设备准备；错过选课时间要及时联系教务老师补选。
:::

## 四、学习方法建议

1. **告别被动学习**：大学课堂节奏快，需要课前预习、课后复习。
2. **多读多写**：文新学院的专业特点决定了阅读与写作的重要性，坚持日常积累。
3. **善用图书馆**：图书馆藏书丰富，是自习与查阅资料的最佳场所。
4. **利用答疑时间**：任课教师有固定答疑时间，有问题主动请教。
5. **重视平时成绩**：作业、课堂表现、小组讨论都可能计入成绩，别只盯着期末。

## 五、图书馆使用

- **入馆方式**：刷校园卡入馆。
- **借阅规则**：凭校园卡借阅，注意借阅期限与续借规则。
- **自习座位**：可通过图书馆系统预约（具体规则以馆内公告为准）。
- **开放时间**：以图书馆公布为准，考试周可能延长开放。

::: tip 小贴士
开学初的「新生入馆教育」一定要参加，会用图书馆的大学生活效率高很多。
:::

## 六、转专业与辅修

- **转专业**：一般在入学后特定时间开放申请，需满足成绩等条件，具体政策以学校规定为准。
- **辅修/双学位**：学校可能开设辅修专业，感兴趣的同学关注教务处通知。

> 相关政策的细节请以学校教务处与学院教务办的最新通知为准。
