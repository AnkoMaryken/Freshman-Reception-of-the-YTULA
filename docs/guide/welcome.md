你好！祝贺你以优异的成绩考入 **烟台大学文学与新闻传播学院**，踏上人生新的征程。学院全体师生热忱欢迎你的到来！

## 一、学院简介

文学与新闻传播学院是烟台大学的重要学院之一，拥有完整的本科与研究生培养体系。学院师资力量雄厚、学科特色鲜明，注重学生的人文素养与实践能力培养。

> 具体专业设置、师资队伍与学科建设情况，以学院官网发布的最新信息为准。

## 二、开学日程概览

入学前后通常会经历以下几个阶段，具体时间安排以学院通知为准：

| 阶段 | 时间（参考） | 主要事项 |
|------|------------|---------|
| 入学前 | 录取通知书发放后 | 网上确认、缴费、准备材料 |
| 报到 | 开学报到日 | 到校报到、办理入住 |
| 入学教育 | 报到后一周内 | 开学典礼、安全教育、专业介绍 |
| 正式上课 | 入学教育结束后 | 领取教材、按课表上课 |

::: warning 注意
以上时间为大致安排，**具体日期请以学院发布的官方通知为准**，切勿轻信非官方渠道的信息。
:::

## 三、报到前须知

1. **及时关注官方通知**：录取通知书、学院新生群、学院官网是获取信息的权威渠道。
2. **谨防电信诈骗**：学校不会通过电话或短信索要银行卡密码、验证码，凡是要求转账的「缴费」「奖学金」通知一律不要轻信。
3. **提前规划行程**：确认报到日期后，尽早购买车票/机票，规划到校路线。
4. **整理必要材料**：对照《入学前准备》中的清单，逐项核对证件与材料。

## 四、开学后可以期待什么

- **丰富的社团活动**：文学社、新闻社、辩论队等学生组织等你加入。
- **多彩的校园生活**：迎新晚会、运动会、文化讲座等活动接连不断。
- **充实的专业学习**：写作、新闻采编、新媒体运营等课程，理论与实践并重。

::: tip 小贴士
大学生活节奏与高中截然不同，请尽早学会自我管理：时间规划、自主学习、与人沟通，都是大学的重要课题。
:::
