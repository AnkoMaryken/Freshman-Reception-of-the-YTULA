# 入学前准备

出发前，建议你对照本清单逐项准备，避免遗漏。**以学校/学院官方通知为最终依据**，本页为常见事项汇总。

## 一、证件材料清单

| 材料 | 说明 |
|------|------|
| 录取通知书 | 原件，报到时核验 |
| 身份证 | 原件及正反面复印件若干份 |
| 证件照 | 一寸、二寸免冠照片（蓝底/白底）各准备 8-10 张，电子版也保存一份 |
| 高考准考证 | 部分学校要求核对 |
| 学生档案 | 按中学要求办理转递，或报到时自带（注意档案密封，不可拆封） |
| 党团组织关系 | 团员证、团员档案、团组织关系介绍信（按通知要求办理） |
| 户口迁移材料 | 自愿迁移；如需迁移，携带户口迁移证等材料 |

::: tip 建议
所有重要证件建议复印 2-3 份备用，并将电子扫描件存入手机或网盘，以备不时之需。
:::

## 二、生活物品清单

学校不统一配备生活用品，可根据个人需要携带或在校园超市购买：

### 床上用品
- 被褥、枕头、床单、被套（宿舍床铺为标准单人床，尺寸可咨询学院）
- 蚊帐或床帘（按需）

### 洗漱用品
- 毛巾、牙刷、牙膏、洗发水、沐浴露、脸盆、水杯
- 衣架、洗衣液

### 衣物鞋袜
- 夏装（报到时天气仍较热）
- 秋装、冬装（烟台冬季较冷，建议准备厚外套、棉衣）
- 运动鞋、拖鞋

### 学习用品
- 笔记本电脑（按专业需求）、U 盘
- 笔记本、笔、文件夹

### 其他
- 常用药品（感冒药、肠胃药、创可贴等）
- 雨伞、保温杯
- 充电器、插线板（注意宿舍用电安全规范）

::: tip 小贴士
大件物品（被褥、收纳箱等）可以选择到校后再购买，或提前邮寄到学校快递点，避免旅途携带负担过重。
:::

## 三、网上办理事项

报到前通常需要在网上完成以下操作（具体以学校通知为准）：

1. **网上报到/信息采集**：登录学校迎新系统，确认个人信息、选宿舍、登记到校方式等。
2. **缴纳学费与住宿费**：按通知要求，通过学校官方渠道缴费，妥善保存缴费凭证。
3. **生源地助学贷款**：需要办理助学贷款的同学，提前联系当地学生资助管理中心。
4. **申请资助**：家庭经济困难的同学，按通知办理绿色通道或提交相关证明材料。

::: warning 注意
所有缴费均通过**学校官方渠道**进行，学校不会安排任何个人代为收费。如遇自称「学长/学姐/老师」的收费要求，请先核实身份并向辅导员确认。
:::

## 四、到校交通规划

- **报到日期确定后**，尽早购买车票/机票。
- 学校通常会在报到日在火车站、汽车站、机场设置**接站点**，具体位置和时间以学院通知为准。
- 也可以选择乘坐公交、出租车/网约车自行前往，规划好路线和预计时间。

## 五、出发前检查

出发前一天，最后核对一遍：

- [x] 录取通知书、身份证、证件照
- [x] 学生档案、党团材料
- [x] 学费缴费凭证
- [x] 常用药品、必备生活用品
- [x] 手机充电器、充电宝
- [x] 报到联系方式（辅导员电话、学院新生群）

::: tip 记得
把辅导员老师的联系方式保存在手机里，路上遇到任何问题都可以随时联系。
:::
